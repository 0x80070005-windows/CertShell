## README.md для CertShell

# CertShell

**Оболочка для управления зашифрованными файлами через виртуальный диск и X.509-сертификат**

Версия: **1.0**  
Лицензия: **GPL-3.0**

## Описание

CertShell — это интерактивная консольная оболочка для работы с зашифрованными файлами. Она обеспечивает:

- **Двухфакторную аутентификацию** (логин + пароль)
- **Пиннинг сертификата** через SHA-256 отпечаток
- **Монтирование виртуального диска** с зашифрованными файлами
- **Интеграцию с CertGuard** для расшифровки файлов по требованию
- **Аудит событий** с логированием всех операций
- **Автоматическую очистку** при выходе

## Возможности

- ✅ Многоуровневая аутентификация (логин, пароль, сертификат)
- ✅ Certificate pinning для защиты от подмены
- ✅ Управление виртуальным диском (mount/umount)
- ✅ Навигация по директориям внутри образа
- ✅ Добавление и удаление файлов
- ✅ Интеграция с CertGuard для дешифровки
- ✅ Аудит-логирование всех действий
- ✅ Автоочистка временных файлов
- ✅ Поддержка терминалов на Linux/macOS/Windows

## Требования

- .NET 8.0 и выше
- Linux или macOS
- Установленный CertGuard
- Образ виртуального диска (`.img`)
- X.509-сертификат с публичным ключом

⚠️ **Windows не тестировался**

## Установка

### Сборка из исходников

```bash
git clone <repository>
cd CertShell
dotnet build --configuration Release
dotnet publish --configuration Release --output ./bin/publish

Готовый бинарный файл: ./bin/publish/CertShell
Первый запуск
Setup Wizard
bash

./CertShell --setup

или
bash

./CertShell --init

Мастер настройки попросит указать:

    Путь к сертификату — где находится ca.crt или certificate.cer
    Путь к образу диска — файл .img с зашифрованными данными
    Точка монтирования — куда монтировать образ (по умолчанию /mnt/virtual_disk/)
    Путь к CertGuard — бинарный файл программы расшифровки
    Логин и пароль — для входа в CertShell

При первом запуске без --setup автоматически запустится мастер.
Использование
Интерактивный режим
bash

./CertShell

Будет запрошены логин и пароль, затем откроется интерактивная оболочка.
Доступные команды
Основные

    ls — показать содержимое текущей директории
    clear — очистить экран
    exit — выход и размонтирование

На корневом уровне

    cd — перейти в директорию внутри образа
    lsdir — показать все директории в корне образа
    mount — смонтировать образ вручную
    add — добавить файл в корень образа
    remove — удалить файл из корня
    open — выбрать и открыть файл из списка

В режиме cd (внутри директории)

    add — добавить файл в текущую директорию
    remove — удалить файл
    open — открыть файл (автоматически расшифрует .enc через CertGuard)
    cd .. — вернуться в корень

Пример рабочего процесса
bash

# Запуск
./CertShell

# Ввести логин и пароль

# Показать директории
lsdir

# Перейти в папку
cd

# Показать файлы
ls

# Открыть зашифрованный файл
open

# CertGuard запустится в отдельном терминале
# Введётся пароль, файл расшифруется и откроется в плеере
# После просмотра файл автоматически удалится

# Вернуться в корень
cd ..

# Выход
exit

Конфигурация

Конфигурация хранится в:

    Linux/macOS: ~/.local/share/CertShell/config.json
    Windows: %APPDATA%\CertShell\config.json

Пример config.json:
JSON

{
  "CertPath": "/mnt/usb/certificate.cer",
  "ImgPath": "/home/user/virtual_disk.img",
  "MountPoint": "/mnt/virtual_disk",
  "CertGuardPath": "/usr/local/bin/CertGuard"
}

Безопасность
Преимущества

    ✅ Двухфакторная аутентификация (логин + пароль)
    ✅ Argon2id для хеширования пароля (64 MiB, 3 итерации)
    ✅ Certificate pinning через SHA-256
    ✅ Аудит-логирование всех операций
    ✅ Автоматическая очистка временных файлов при выходе
    ✅ Права доступа 0600 на конфиг-файлы (Linux/macOS)
    ✅ Таймаут попыток входа (защита от перебора)

Ограничения

⚠️ Не защищает от:

    физического доступа к машине с включённой сессией
    компрометированной ОС
    вредоноса, установленного на систему

⚠️ Важное замечание:

    На Windows права доступа не настраиваются автоматически
    Логин хранится как хеш, но локально на машине
    Для максимальной безопасности используйте шифрование всего диска (BitLocker/LUKS)

Аудит-логирование

Все события логируются в:

    Linux/macOS: ~/.local/share/CertShell/audit.log
    Windows: %APPDATA%\CertShell\audit.log

Примеры логов:
Code

2026-09-28T12:34:56.1234567Z [INFO] session_start
2026-09-28T12:35:10.1234567Z [INFO] mount img=/home/user/disk.img point=/mnt/virtual_disk
2026-09-28T12:36:05.1234567Z [INFO] open file=video.mp4.enc dir=videos
2026-09-28T12:37:20.1234567Z [INFO] session_exit

Поддерживаемые форматы файлов

CertShell может автоматически открывать:

Изображения:

    .jpg, .jpeg, .png, .bmp, .tif, .tiff, .webp

Видео:

    .mp4, .avi, .mkv, .mov

Текст:

    .txt, .log

Для других расширений будет предложен выбор типа файла.

Code

gnome-terminal, konsole, xfce4-terminal, xterm, alacritty, kitty, foot

Если подходящий терминал не найден, установите один из перечисленных.
